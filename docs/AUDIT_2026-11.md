# Audit, November 2026 (running log)

Nothing here is committed. Method: static scans of main.js / preload.js / lib, fuzzing the text parsers, the preview lint on every page (en/fi, free/premium, light/dark, several widths), a page-by-page console and leaked-placeholder sweep in the browser pane, and the full test and check suites after each change.

## Fixed
| Area | Finding | Fix |
|---|---|---|
| Reliability | `cuWrite` (state files: Game time sessions, Startup, Apps, Games, Cleanup rules...) wrote in place: a crash mid-write left a corrupt file and `cuRead` then silently returned the default, forgetting sessions and pins. | Temp file + rename, previous good copy kept as `.bak`, read falls back to it. |
| Reliability | Direct `writeFileSync` on files that matter: GPU power-limit sentinel (a torn write means the limit is never restored), Firefox `user.js` / Discord `settings.json` (Apps tab writes), custom games, game history, speed history, cleanup history, analytics, and the journal rotation (undo history). | `lib/atomic-write.js` used for each; journal rotation uses temp + rename through its injected fs. |
| Reliability | Game watcher ran on a 5 s interval with awaits inside (tasklist, 400 ms waits, restore): a slow tick could overlap the next and double-apply or double-restore. | In-flight guard with `finally`. |
| UI crash | `gsExclusionInit` and `loadRPDiskUsage` threw (unhandled rejection) when the main process returned null. | Null-safe destructuring. |
| Accessibility | Segmented controls (`j-seg-item`) were 24 px tall and flagged as too small on every page that uses them (about 50 findings). | 26 px. |
| Accessibility | Diagnostics links were 17 px tall (15 findings). | 24 px minimum. |
| Contrast | Premium pitch button text was white on the accent in the light scheme (3.3:1) on every locked tab; Cleanup "Premium" badge and BIOS segmented "on" state also under 4.5:1. | Use `--on-accent` / `--c-accent-fg`; higher specificity so the page-wide button colour no longer wins. |
| UX | Restore points had two primary buttons visible at once (stale banner and empty state). | Secondary variant for those two. |
| i18n | Finnish text missing for the `vbs-disable` warning (a security warning shown in English). | Added; baseline updated. |
| i18n | The Games page looked up `root.LANG`, which is not a window property, so its singular strings ("1 game") never applied. | Use the page-level `LANG` / `currentLang`. |
| Startup tab | Verdict counted Store apps it cannot switch ("1 of 7 can go" with no button). | Verdict counts switchable programs only (test added). |
| Scheduler (Premium) | Tasks are registered as SYSTEM, so `%TEMP%`, `%LOCALAPPDATA%` and `%USERPROFILE%` in the commands pointed at SYSTEM's profile: Clear Temp Files cleaned the wrong Temp, Clear NVIDIA cache and Clear Downloads did nothing. "Free RAM (Empty Standby List)" never emptied the standby list: it ran a GC in a throwaway process and **emptied the Recycle Bin for all users**. | The user's real folders are written into the command as quoted literals when the task is created. Free RAM now runs the same standby purge as the CPU & Memory tab and leaves the Recycle Bin alone. Clear Downloads now removes only files not changed for 30 days (now that it really works, the old "delete everything" would have been a data-loss trap). EN and FI texts and the confirm updated. |

## Checked and fine
- BrowserWindow settings (contextIsolation, sandbox, no nodeIntegration) on every window; `open-external` and `open-path` allowlists; no `eval`; no unreviewed shell interpolation (scan-injection passes).
- preload keys vs `ipcMain` handlers: all wired (the loop-registered pulse2 / gamecfg / fivem2 handlers included).
- Items from the earlier release audit that were still listed (fix-2502 permissions, Firefox places.sqlite, .nuget wipe, IPv6 value, Defender exclusions): all already fixed in the code.
- 18 text parsers fuzzed with garbage strings: none throw on strings (only on wrong non-string types, which no caller passes).
- Console and placeholder sweep over 21 pages in free/fi and premium/en: clean after the fixes above.

## Open / not verifiable here
- Existing `JT_*` scheduled tasks created by older versions keep their old (wrong) commands until the user re-creates them.
- Scheduler "Windows Update" option removed (it ran as SYSTEM, which has no desktop, so it did nothing). Already-scheduled tasks of that kind still list correctly.
- `npm audit`: `ws` 7.x (via discord-rpc, only used for its websocket transport, which Jylli does not use) and `js-yaml` (via electron-updater / builder). Not changed here because the fix touches the lock file and install scripts.

- Dashboard light-scheme contrast findings sit on the always-dark 3D stage (documented exception).
- Network tab: one `span.mono` at 10.12 px.
- Anything needing the real built app, elevation, or a real game.
