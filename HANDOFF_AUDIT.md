## Tooling gotchas (cost me time)
- The Bash tool halves backslashes inside heredocs (`\\s` arrives as `\s`, `\\b` became a backspace character). Do not type regexes or Windows paths with backslashes in heredoc scripts. Build them with `String.fromCharCode(92)`, use `[0-9]`/`[ ]` classes, or use the Write tool for whole files.
- A heredoc containing mixed quotes can fail to parse as a whole: use the Write tool for new files.
- No python on this machine; edit with small `node` scripts (pattern: read file, `includes` check, `replace(a, () => b)`, write). Scratch scripts live in the session scratchpad, not the repo.
- main.js (~826KB) and index.html (~970KB): never read in full; Grep, then `sed -n` ranges.
- `npm start` piped through a filter exits at once. Launch the app with `node_modules\electron\dist\electron.exe .` instead.
